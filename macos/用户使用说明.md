# DY 直播间助手 · 简明使用手册

更新：2026-10-14 · 版本 6.1.21-mac.1（独立Mac测试版）

## 1. 快速开始

1. 保留整个软件文件夹，双击 `DYLiveAssistant.exe`。不要删除 `_internal`。
2. 选择“联网激活”或“旧版离线激活”，输入对应卡密。
3. 登录抖音并保存登录状态，核对收货地址、商品和规格。
4. 核对填写信息，启动后会真实提交订单；确认待付款后由你处理后续付款。

电脑需安装 Edge 或 Chrome。联网卡密首次激活绑定电脑；换电脑或续期请联系管理员。旧离线卡密仍可使用，不受网站停用管理。

## 2. 秒杀推荐：详情页锁单

**优先推荐用于短时间补库存的商品。** 提前打开商品详情，减少开售后找商品、打开详情的步骤，争取更好的抢单机会。实际成功率受库存、网络和平台风控影响，不保证抢到。

### 怎样开启

1. 打开“DY直播间商品秒杀”，填写直播间链接。商品名称（请复制完整的商品名称）和商品编号至少填写一个；两项都填时任一匹配即可，但对应多个商品会停止。
2. 秒杀统一使用详情页锁单，启动后立即进入目标详情并持续等待。建议在商品开始抢购的一分钟内启动；这是建议，不限制启动时间。
3. 浏览器打开后，让程序等待；不要随意切换商品或关闭浏览器。点击“停止”可结束任务。

### 程序会怎样抢

提前进入详情 → 等待补库存 → 商品、规格及数量确认且提交按钮可用 → 原生点击一次提交 → 确认新订单号和“待付款” → 停止。

- 秒杀锁单只买 **1件**，确认待付款即完成。
- 确认锁单后，由你自己核对订单并完成后续付款；程序不会继续付款或取消订单。
- 详情页锁单先进入详情，以页面变化监听为主；默认每10秒重新打开或刷新目标详情，补充获取更新；高级设置最低可设1000毫秒（1秒），小于1秒会按1秒执行。规格和支付按钮可用时立即核对提交，无需等待下次刷新。
- 持续等待到确认待付款、你点击停止或出现需要停止的异常。
- 只有二维码、灰色按钮或“已抢完”时，不会提交。

**注意：按钮名称不代表一定不会扣款，实际行为以平台和账号为准。请先确认支付设置。**

## 3. 商品与规格怎么核对

商品名称或编号任一匹配且结果唯一即可进入详情；商品、规格和订单身份的必要核对始终执行。

填写规格时必须逐项选择并确认；秒杀指定规格尚未出现、缺货或暂不可选时持续等待，不改选其他款式。未填写但需要选择时，每组选择第一个可用选项并确认。匹配有歧义或选择结果不明会停止。可提交时保留商品和规格核对记录，确认订单或提交尝试结束后再保存截图；截图会标明实际保存阶段，不拖慢支付点击。规格金额变化不会阻止提交。

批量下单保持原来的规格校验和逐笔确认规则；缺少指定规格时停止。已尝试提交但结果不明时，两种模块均不重复下单。

多规格选中后，程序会先检查支付按钮是否稳定、无遮挡且能接收点击；这一步不会下单。秒杀遇到临时遮挡或按钮重绘会继续等待并重新核对，批量模式遇到未就绪入口会停止。实际提交只执行一次，结果不明确不会重复点击。原始点击错误会写入诊断记录。

## 4. 运行日志怎么看

- **持续监控中**：程序一直在检测，只是状态日志每5秒更新，不是每5秒才检测。
- **监控时间 / 状态 / 检测周期ms**：表示已等待多久、检测是否正常、最近一次检测周期；不是保证下单成功的速度。
- **锁单成功**：已识别新订单号和待付款状态。点击按钮不等于成功；未确认时先查抖音订单，别立即重启抢购。

“检测可提交→点击”和“点击→待付款确认”为毫秒耗时；“打开链接→确认”包含开售前等待，不等于商家上架到锁单的时间。

## 5. 批量下单与网络测速

批量下单：填写直播间链接、商品名称或编号、订单数和每单数量；多规格商品填准确的选项名称。按顺序处理，不是同时抢多个商品。

### 多规格怎么填

- 手机：`机身颜色=曜石黑；存储容量=12GB+512GB`
- 电脑：`套餐类型=套餐一；硬盘容量=1TB`
- 日常用品：`规格名=规格名称`

名称以商品页面为准，不同规格组用中文分号 `；` 分隔。未填写时，每组自动选择第一个可用选项并确认；只想买指定款式时请填写准确规格。

### 多账号依次下单（默认关闭）

1. 点“管理账号”，新增账号并逐个登录；登录后在主窗口点“完成登录并保存”。“原有账号”使用原来的登录资料。
2. 选中账号，勾选“加入队列”，填写该账号的订单数、每单数量，点“保存修改”；用上移/下移安排顺序。
3. 开启“多账号依次下单”，核对确认窗口里的顺序后执行。商品和规格共用当前表单。
4. 验证码、库存不足、结果不明等会停止整队并保留当前浏览器。先核对订单，勿直接重跑。

账号备注不代表平台身份，请本人核对；移除账号不会删除登录资料。多账号不会提高秒杀速度，也不绕过平台限制。

网络测速：用于了解当前连接表现。延迟低有利于及时响应，但不能据此算出抢单成功率。

## 6. 选择浏览器与常见问题

在“退出当前账号”旁点击“选择浏览器”，选择“自动选择”、Microsoft Edge 或 Google Chrome，然后保存。两个下单模块和登录都会使用此设置；它不修改 macOS 默认浏览器。明确选择的浏览器启动失败时提示原因，不自动换浏览器。首次切换可能需要重新登录；各浏览器资料分别保存，原资料保留。任务、登录、网络检测或更新期间不能切换。

秒杀监测到目标卡片从不可购买变为可购买，而详情仍为二维码或旧库存时，会立即重新核对并打开一次目标详情；其他情况按设置间隔补充刷新。扫码页面没有网页支付按钮时不会点击二维码或假报成功。

- **换一个抖音账号**：在“完成登录并保存”旁点“退出当前账号”，确认后重新扫码登录，再点“完成登录并保存”。仅清除当前资料中的抖音登录状态，不删除其他账号、商品设置或激活信息；运行任务、测速或更新时不可退出。

- **出现验证码/人机验证**：识别到后暂停刷新和点击，保留浏览器。你手动完成验证，正确商品详情恢复后自动继续。
- **详情显示服务异常**：暂停刷新和点击，不自动反复重试；请人工恢复目标商品详情，核对成功后继续。降低刷新频率不能保证平台始终允许访问。
- **提交后才出现验证**：完成验证并核对当前订单；程序不重复提交或继续付款。
- **没抢到 / 商品不符 / 结果不明**：先看日志和平台订单，核对商品、价格、规格、数量及网络。仍有问题，再发送脱敏诊断截图。
- **停止任务**：点击“停止”。人工验证时别随意停止，以免关闭需要处理的浏览器。

软件不绕过验证码，不保证库存或成功率。截图请遮住姓名、电话、地址、订单号和二维码；不要发送支付密码、登录资料或激活文件。

## 7. Mac版本安装和更新

Mac独立更新通道尚未上线。检查更新只显示说明，不会下载Windows包。获取维护者提供的新Mac安装包，退出旧软件后再安装；不会自动恢复下单任务。账号资料与偏好保存在 ~/Library/Application Support/DYLiveAssistantMac。新Mac属于新设备，原绑定Windows的卡密需要联系管理员处理。公开源码构建不包含私有离线卡密哈希，默认使用联网卡密；离线激活需维护者在私有构建环境加入原哈希清单。

导出更新诊断仅保存Mac版本和架构信息，不含卡密或浏览器资料。

公告无需激活即可查看。启动时联网检查新公告，非模态弹窗展示内容和发布时间；“稍后查看”会在下次启动再次提醒，“关闭”记录已读。入口位于“导出更新诊断”旁，左侧选择历史公告、右侧查看正文和发布时间，可重新加载；断网或服务异常不影响下单、更新和授权。

## 本地异常诊断验证

本版补上“服务异常”的识别。出现服务异常或验证码时暂停刷新和点击，保留浏览器供人工处理；恢复后重新确认目标详情。刷新前页面若已变化，先重新核对再决定是否刷新。正常刷新间隔保留，最低1秒，不能保证避免平台限制。

诊断记录会标明两次主动刷新之间发现的规格或支付按钮变化；这不能单独证明平台推送库存，也可能来自页面自身请求或规格操作。网络日志补充失败原因和发生阶段，地址去掉查询参数；不记录响应正文。

本版商品规格无需勾选，填写即可生效。使用指南随选中的商品秒杀/批量下单模块切换。批量数量设置后只允许提交前有限等待按钮重绘，确认待付款才计数，结果不明确不重试。

## 公告与反馈

公告窗口放大，历史标题和正文分开显示。软件启动后及运行中约每60秒后台检查新公告；断网失败后自动重试。任务运行期间仅显示“公告（新）”，结束任务后弹出，避免遮挡操作；已关闭的同一版本公告不反复提示，编辑过的公告会再次提醒。“稍后查看”本次运行不重复弹出，下次启动仍可提醒。

公告旁的“向我反馈”可填写问题及联系方式，主动选择图片、日志、JSON、ZIP或PDF。最多5个附件，每个10MB、合计20MB；只上传自己选择的内容，提交前去除个人信息。任务或网络检测运行时请结束后再提交，失败保留填写内容。反馈接收接口已上线；Mac端实际收发仍需在Mac验证。

批量兼容真实“订单已提交，待付款＋金额”弹窗。新订单必须与本笔商品和规格匹配；弹窗未展示件数时，使用本笔原生提交前已核对数量，并明确记录证据来源。弹窗显示数量时必须相符。确认新待付款后才计数并恢复下一笔，不继续付款，不点击叉；结果不明时停止，不重复提交。
